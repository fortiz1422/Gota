# Gota Logo Kit

## Direction

The current `gota.` mark works because it does not behave like a startup mascot or a decorative emblem. It is a typographic signature: compact, calm, and legible at product scale. The identity lives in proportion, weight, and the asymmetric tension created by the final dot. That restraint should be preserved. Any extension of the mark has to feel like a careful continuation of the product language already present in the login hero and desktop shell, not a rebrand.

The core form is deliberately plain in structure and precise in finish. `gota` stays dense, low-tracking, and confident, using the same heavy DM Sans voice the app already uses. The period is not punctuation in a neutral sense; it is the only explicit accent. It closes the word, introduces temperature, and gives the identity its smallest memorable hook. The work must feel meticulously tuned rather than embellished.

Color should remain in the same cold family as the current interface. On light surfaces, the primary wordmark resolves in `text-primary` with the point in `primary`. On dark or blue-zone contexts, the letters hold in white and the point shifts to the lighter blue used in the landing hero. This keeps the brand recognizable while respecting the current product contrast system. Monochrome variants should exist, but only as utility versions.

The logo kit should therefore prioritize usage logic over novelty. The main asset is the wordmark. Secondary assets are support tools: an inverse version, a monochrome version, a micro-scale version with spacing adjusted for small reproduction, and a monogram extracted from the same vocabulary for avatars, favicons, or splash contexts. The monogram should feel like a crop from the same typographic world, not a separate symbol system.

Spacing and reduction matter more than ornament. Clear space should be defined off the diameter of the point, since the point is the smallest high-signal unit in the mark. Minimum-size behavior should preserve the point as a crisp counterweight, avoiding thin or airy treatments that make the kit feel generic. The result should read as a product identity system made with discipline: understated, exact, and clearly authored.
